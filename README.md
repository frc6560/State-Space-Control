# State-Space-Control

Interactive state-space control experiments.

- [Swerve-drive LQR simulation](swerve-lqr-sim/README.md) — a dependency-free browser simulation with keyboard driving, chassis velocity LQR control, four-module inverse kinematics, and a documented FRC mass/inertia model.
- [Intake state-space control](intake-state-space/README.md) — a rack-and-pinion intake model with explicit state-space matrices, LQR feedback, an X44 deployer/X60 roller configuration, the three requested operating modes, and a shooting oscillation mode.
